## Autonomy level

Agent can autonomously retrieve evidence, synthesize insights, verify grounding, and create draft recommendations.

Agent CANNOT make an unapproved roadmap commitment. write_roadmap() requires explicit PM confirmation.

## Controls

- **Kill switch:** max_steps = 5

Abort when:

More than 2 tool errors occur in a run.
The agent reaches 5 steps without completing verification.
The 30s wall-clock timeout is reached.

On abort, return the best available partial output with an explicit incomplete/error status. Never silently truncate or continue beyond the limit.
- **Rate / cost caps:** Every retrieval tool returns source evidence plus a relevance score so the agent can distinguish supported evidence from weak matches.

search_strategy(query) → {matches:[{clauseText,heading,score}]}
read_tickets(filter) → {tickets:[{id,summary,evidence,occurrences,score}]}
draft_priority(insight_id,priority,rationale) → {insight_id,priority,rationale,status}
write_roadmap(insight_id,priority) → {insight_id,priority,status}

Retrieval outputs must include the underlying source evidence. The agent cannot treat an unsupported summary as evidence.
- **Escalate-on-stuck:** If strategy retrieval or supporting evidence fails, the agent returns the insight as Unverified with the missing evidence clearly stated.

If tool errors exceed the allowed limit or the workflow times out, abort and return the best available partial output with the failure state surfaced to the PM.

## Monitoring

**Confidence thresholds (map to actions):**

≥ 80% confidence: Insight can be surfaced to the PM as verified if strategy evidence and supporting product evidence are present.
70–79% confidence: Surface to PM with a lower-confidence warning and supporting evidence.
< 70% confidence: Mark Unverified and hand back to PM; do not allow roadmap commitment.
No supporting strategy clause: Always Unverified regardless of confidence score.

Confidence triggers an action, not just a label: lower confidence increases human review and blocks consequential writes.

**Checkpoints:**

Confidence <70%: PM review required.
Missing or conflicting strategy evidence: PM review required.
Unverified insight: cannot proceed to roadmap commitment.
Any write_roadmap() action: explicit PM confirmation required.

**North Star (re-read every loop):**

You are Juno. Synthesize fragmented customer and product signals into evidence-backed insights that reduce PM analysis time while preserving human judgment.

## Permissions

Agent can READ the RocketShip Strategy KB and product/customer signal corpus.

Agent can WRITE draft priorities for PM review.

Agent CANNOT modify source evidence, delete records, send customer-facing communications, or write to systems outside the approved tool set.
