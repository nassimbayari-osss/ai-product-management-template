## Goal

Synthesize fragmented customer and product signals into evidence-backed insights that reduce PM analysis time while preserving human judgment. (Efficiency / risk mitigation)

**Primary actor:** Agent + Human-in-the-loop

## Trigger

New customer interview transcript or product-signal batch is submitted to Juno for analysis.

## Steps & tools

**Pattern:** ReAct (single-agent reason-act-observe loop)

| Step | Action | Tool / model | Guardrail |
|---|---|---|---|
| 1 | Read the new transcript or product-signal batch. | search_strategy(query), read-only | Agent can READ the RocketShip Strategy KB and product/customer signal corpus. Agent can WRITE draft priorities for PM review. Agent can commit roadmap priorities only after explicit PM confirmation. Agent CANNOT modify source evidence, delete records, send customer-facing communications, or make unapproved roadmap changes. |
| 2 | Retrieve relevant strategy clauses from the RocketShip Strategy KB. | read_tickets(filter), read-only |  |
| 3 | Retrieve supporting customer/product evidence from the ticket corpus. | draft_priority(insight_id, priority, rationale), write, draft only |  |
| 4 | Synthesize recurring problems and strategic alignment with evidence-backed rationale. | write_roadmap(insight_id, priority), write, requires PM confirmation |  |
| 5 | Verify grounding and surface the insight to the PM. | _ |  |

**Schemas**

-search_strategy → {matches:[{clauseText, heading, score}]}
-read_tickets → {tickets:[{id, summary, evidence, occurrences}]}
-draft_priority → {insight_id, priority, rationale, status}
-write_roadmap → {insight_id, priority, status}

**Memory (in or out of scope)**

- **Episodic:** In-scope, tool results, retrieved strategy clauses, supporting evidence, intermediate insight candidates, and verification results. Lifetime: end of run.
- **Semantic:** In-scope, RocketShip strategic taxonomy + Juno system prompt + PM-defined synthesis rules. Lifetime: indefinite, refreshed when strategy changes. Out of scope, do NOT persist customer-specific contracts or PII.
- **Working:** In-scope, current transcript or signal batch, retrieved strategy clauses, supporting tickets, current insight candidates, and verification state. Held in working context only.
- **External:** RocketShip Strategy KB (read), product/customer signal corpus (read), PM workflow state (read/write only where explicitly authorized).

## Human-in-the-loop

PM reviews synthesized insights before using them for prioritization. Juno hands control back when evidence is insufficient, conflicting, or unverified.

## Success & failure

- **Done when:** Success: Evidence-backed insights synthesized and verified → return to PM for review.
Failure: >2 tool errors in a run → log + abort.
Escalation: Strategy evidence is missing, conflicting, or insight cannot be verified → mark Unverified + hand to PM.
Timeout: 30s wall clock → return partial output with incomplete status.
- **Fails safe when:** Agent can READ the RocketShip Strategy KB and product/customer signal corpus. Agent can WRITE draft priorities for PM review. Agent can commit roadmap priorities only after explicit PM confirmation. Agent CANNOT modify source evidence, delete records, send customer-facing communications, or make unapproved roadmap changes.
