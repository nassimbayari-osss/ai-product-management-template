## Golden set

50 fixed insight-generation requests covering standard requests, ambiguous evidence, conflicting evidence, weak evidence, and strategy-misalignment cases.
Versioned whenever the test set changes.

## Release gate

**Hard gates (auto-block):**

Fabricated evidence
Unsupported substantive claims
Unverified insight allowed to trigger write_roadmap
Permission or safety check failure
Required output/schema failure

**Soft gates (PM sign-off):**

Automated score below the 95% target but above hard-gate thresholds
Increased rejection/regeneration rate
Human-evaluation score below 4.0/5
New failure pattern not represented in the golden set

**User-feedback layer (online):** cadence Continuous; reviewed weekly.; owner PM + Product/AI team; PM reviews trends and Product/AI investigates recurring failure patterns..
